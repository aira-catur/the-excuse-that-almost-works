Entry for the make.fun bounty [The Excuse That Almost Works](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5).

A deterministic, standard-library-only Python program (`main.py`) that writes a single line — the excuse a gamer texts the boss to skip work on GTA 6 launch week — to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The line is 86 characters and 19 words, inside the competition's 1–140 character and at-most-20-words gate.

The excuse:

> Can't get in today, my car key battery died and the spare is in my desk drawer at work
